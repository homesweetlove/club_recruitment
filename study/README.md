# Study Archive

C 언어, Python, 개발 영어, 기초 수학을 주제로 정리한 정적 학습 자료입니다.

- [학습 목록](./index.html): 카테고리별 필터와 글 카드 목록
- `css/style.css`: 학습 페이지 및 글 스타일
- `js/app.js`: 글 목록 데이터, 카테고리 필터, 페이지 이동
- `posts/`: 총 8개의 학습 글

## 실행

저장소 루트에서 `python -m http.server 8000`을 실행한 뒤 `http://localhost:8000/study/`에 접속하세요.

외부 서버나 데이터베이스 없이 HTML, CSS, JavaScript만으로 동작합니다.

[저장소 메인 README로 돌아가기](../README.md)
